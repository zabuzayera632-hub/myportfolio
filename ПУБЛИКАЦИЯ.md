# Как опубликовать сайт emblem_a

Короткая версия: **хостинг Beget + домен .ru (или .com) + загрузка одного архива `emblem_a-site.zip`.**
Весь путь — около часа работы и до суток ожидания, пока домен «разойдётся» по интернету.

---

## 0. Что публикуем

| Что | Где лежит | Нужно на хостинге? |
|---|---|---|
| Готовый сайт | папка `dist/` | ✅ да — это и есть сайт |
| То же одним файлом | `emblem_a-site.zip` | ✅ его и загружаем |
| Исходники (`build.py`, `i18n.py`, `assets/`, `serve.py`) | корень проекта | ❌ нет, только у вас на компьютере |
| Бэкапы `_backup_*` | корень проекта | ❌ нет |

Архив создаётся сам при каждой сборке (`python3 build.py`). В нём 100 файлов, около 9 МБ, включая скрытый `.htaccess`
(переход на https, защитные заголовки, кэш, страница 404).

---

## 1. Почему Beget, а не Netlify / Vercel / Cloudflare

- Часть клиентов — в России. Cloudflare Pages, Netlify и Vercel из России открываются нестабильно или не открываются
  (ограничения провайдеров с 2025 года). Сайт-портфолио, который у клиента не открылся, — потерянный заказ.
- Российский хостинг одинаково хорошо открывается и из России, и из других стран.
- Beget: бесплатный SSL (https) на всех тарифах, 30 дней бесплатного теста, файловый менеджер умеет распаковывать zip.

**Тариф:** самый простой подходит — сайту не нужны PHP и базы данных.
- «Blog» — 420 ₽/мес (при оплате за год), домен покупается отдельно;
- «Start» — 590 ₽/мес, **1 домен в подарок** — часто выходит выгоднее, чем Blog + домен.

> Цены — с сайта beget.com на октябрь 2026. Проверьте перед оплатой.

Альтернативы: **Timeweb** (то же самое, другой интерфейс), **Yandex Object Storage** (дешевле, но настройка техничнее).

## 2. Домен

**Важно:** в доменах нельзя использовать нижнее подчёркивание, поэтому `emblem_a.ru` не получится.
Варианты, которые стоит проверить в поиске доменов:

- `emblem-a.ru` — ближе всего к нику;
- `emblema.ru`, `emblema-ai.ru`, `emblem-ai.ru`;
- `.com` вариант (`emblem-a.com`) — если важны зарубежные клиенты.

Купить проще всего **прямо в Beget** (раздел «Домены»): тогда ничего настраивать не нужно, домен сразу привяжется к хостингу.

Если домен уже куплен в другом месте (REG.RU, Timeweb, nic.ru): в панели того регистратора найдите
«DNS-серверы» / «Серверы имён» и пропишите четыре сервера Beget:

```
ns1.beget.com
ns2.beget.com
ns1.beget.pro
ns2.beget.pro
```

Изменения вступают в силу от 4 до 72 часов.

## 3. Подготовить сайт под домен (в VS Code)

1. VS Code → **File → Open Folder…** → выберите папку `ai-portfolio`.
2. Откройте файл `build.py`. В самом начале есть строка:
   ```python
   SITE=""
   ```
   Впишите ваш домен с https и без косой черты в конце:
   ```python
   SITE="https://emblem-a.ru"
   ```
3. **Terminal → New Terminal** и выполните:
   ```bash
   python3 build.py
   ```
   Должно появиться `ok — site in dist/, archive emblem_a-site.zip` — уже без предупреждения про SITE.

Что это даёт: правильные ссылки для поисковиков (canonical), карту сайта `sitemap.xml` и
**картинку-превью** со ссылкой — когда вы отправите адрес сайта в Telegram, появится обложка с вашим фото.

## 4. Загрузить сайт на Beget

> Порядок важен: **сначала SSL (шаг 4.2), потом файлы (шаг 4.3)** — в архиве есть переадресация на https,
> и без сертификата браузер покажет ошибку.

### 4.1 Создать сайт
Панель Beget → **«Сайты»** → создать сайт (например `emblem-a`) → привязать к нему ваш домен.
У сайта появится папка `public_html` — туда и кладём файлы.

### 4.2 Включить https
Панель → **«SSL-сертификаты»** → выбрать домен → **бесплатный сертификат (Let's Encrypt)**.
Отметьте и `emblem-a.ru`, и `www.emblem-a.ru`. Выпуск занимает от нескольких минут до часа.
Сертификат продлевается автоматически.

### 4.3 Загрузить архив
1. Панель → **«Файловый менеджер»** → папка вашего сайта → `public_html`.
2. Удалите то, что там лежит по умолчанию (обычно заглушка `index.html` / `index.php`).
3. Загрузите `emblem_a-site.zip` (кнопка «Загрузить»).
4. Правый клик по архиву → **«Распаковать»** прямо в `public_html`.
5. Удалите сам zip-файл из `public_html`.
6. Включите показ скрытых файлов и убедитесь, что `.htaccess` на месте.

Должно получиться так:
```
public_html/
├── .htaccess
├── 404.html
├── index.html, cases.html, prices.html, contacts.html
├── case-*.html (7 шт.)
├── robots.txt, sitemap.xml
├── assets/
└── en/
```

## 5. Проверить после публикации

- [ ] `https://ваш-домен` открывается, в адресной строке замок.
- [ ] `http://ваш-домен` и `https://www.ваш-домен` сами переходят на `https://ваш-домен`.
- [ ] Работают все страницы: главная, кейсы, цены, контакты, каждый кейс, английская версия (кнопка EN).
- [ ] Несуществующий адрес (`/qwerty`) показывает страницу «Такой страницы нет».
- [ ] С телефона: первый экран, лента кейсов листается свайпом, отзывы, меню.
- [ ] Ссылку на сайт отправить себе в Telegram — появилась обложка с фото.
  Если Telegram успел запомнить старый вид ссылки, отправьте её боту **@WebpageBot**, он обновит превью.
- [ ] Видео в кейсах открываются (они идут с Google Диска).

## 6. Чтобы сайт находили

1. **Яндекс Вебмастер** — webmaster.yandex.ru → «Добавить сайт» → подтвердить (проще всего — загрузить их
   html-файл в `public_html`) → «Индексирование → Файлы Sitemap» → добавить `https://ваш-домен/sitemap.xml`.
2. **Google Search Console** — search.google.com/search-console → то же самое: добавить сайт, подтвердить, отправить sitemap.
3. Ссылку на сайт — в описание Telegram-профиля, позже на Behance.

**Аналитика (по желанию):** Яндекс Метрика → создать счётчик → номер вписать в `build.py` в строку `METRIKA=""`
и пересобрать. Политика безопасности сайта подстроится сама. Вместе с Метрикой нужно короткое уведомление о cookie
(по 152-ФЗ) — скажите, и я его добавлю.

**Почта на домене (по желанию):** в Beget можно создать ящик вида `hello@ваш-домен` — выглядит профессиональнее gmail.
Тогда поменяйте почту в `build.py` (список `CONTACTS`) и пересоберите.

## 7. Как обновлять сайт потом

1. Меняете тексты / картинки в VS Code (файлы `build.py`, `i18n.py`, папка `assets/`).
2. Проверяете локально:
   ```bash
   python3 build.py && python3 serve.py
   ```
   и открываете http://127.0.0.1:8765/ (остановить сервер — `Ctrl+C`).
3. Загружаете новый `emblem_a-site.zip` в `public_html` и распаковываете **с заменой файлов**.
   Если поменялась одна-две страницы — можно загрузить только их из папки `dist/`.

После правок стилей или скриптов в `build.py` поднимайте номер версии (`v=42` → `v=43` и т.д.), чтобы у посетителей
сразу подтянулись новые файлы, а не старые из кэша браузера.

## 8. Если что-то пошло не так

| Симптом | Что сделать |
|---|---|
| «Сайт не найден» спустя час | Домен ещё не разошёлся — подождите до 24–72 ч. Проверьте NS-серверы (шаг 2). |
| «Подключение не защищено» | SSL ещё выпускается или не отмечен `www` — шаг 4.2. |
| Бесконечная переадресация | Временно переименуйте `.htaccess` в `_htaccess`, напишите в поддержку Beget (она круглосуточная). |
| Открывается заглушка Beget | В `public_html` остался их `index.php` — удалите. |
| Нет стилей, «голый» текст | Архив распаковался во вложенную папку — файлы должны лежать прямо в `public_html`. |
